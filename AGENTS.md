# AGENTS.md

The instructions for an agent working in this repository live in `CLAUDE.md`,
beside this file. That file holds the only copy of them, and this one names it
so that a tool which looks for `AGENTS.md` still finds the way there.

The project documents it routes to are `docs/STATUS.md` for the state of the
code and the structure map, `docs/TODO.md` for the open work, `docs/SPEC.md`
for the product requirements, `docs/STYLE.md` for the rules on prose, and
`docs/RUST_PORT.md` for the engine migration plan.
